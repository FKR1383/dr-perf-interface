# V8 interpreter and runtime regions

This group contains 50 C++ source regions from V8 revision
`736a2cbec441e85b68c742215d15318abfeae707`:

- 36 `javascript-runtime` regions in native runtime and scope functions.
- 14 `bytecode-generation` regions in the Ignition bytecode generator.

The pristine snapshots cover:

- `src/runtime/runtime-array.cc`
- `src/runtime/runtime-object.cc`
- `src/runtime/runtime-scopes.cc`
- `src/runtime/runtime-strings.cc`
- `src/interpreter/bytecode-generator.cc`

Each `region.patch` applies independently at the V8 source root. A patched V8
build must make [`drperf_bench_region.h`](../support/drperf_bench_region.h)
available on the compiler include path and must link the PerfMark implementation
used by that header. The cases are collected against the pinned source revision
and have not been built in this workspace.

The runtime regions are native fallback paths reached by particular JavaScript
operations. A bounded workload description identifies a plausible trigger shape,
but it does not guarantee that a given V8 build, optimization state, or `d8`
configuration will enter that fallback. These markers therefore do not imply
that every JavaScript operation passes through the marked runtime function or
through Ignition interpreter dispatch.

The bytecode-generation regions run while V8 compiles JavaScript into Ignition
bytecode. Their markers measure generator work; they do not measure execution of
the generated bytecodes.
